# ASH-MIL: Anatomy-Structured Hierarchical MIL for Weakly-Supervised Thoracic Disease Detection in Chest X-rays (MICCAI 2026)

Jeongin Kim, Sohyun Ahn, Seo Young Kang, JaeYi Sung, Soomin Kim, Sungho Cho, Rena Lee, Kwanchang Kim, Junhyug Noh

[[`Paper`](#)] [[`Project`](https://jn-kim.github.io/ash-mil/)] [[`BibTeX`](#citation)]

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Features

* Weakly supervised thoracic disease detection and localization using only image-level disease labels.
* Anatomy-guided query encoding with hierarchical MIL to aggregate evidence across queries and anatomical branches.

## 0) Environmental Setup

```bash
cd ash-mil
conda create -n ash-mil python=3.10 -y
conda activate ash-mil
pip install -r requirements.txt
```

## 1) Download datasets

### CXR8
- [Images and labels (Kaggle)](https://www.kaggle.com/datasets/nih-chest-xrays/data)
- COCO-style bbox annotations (converted from `BBox_List_2017.csv`):
  - `data/cxr8/coco_det/annotations/instances_val2017.json`
  - `data/cxr8/coco_det/annotations/instances_test2017.json`

### MIMIC-CXR

1. Held-out annotations

   ```bash
   git clone https://github.com/leotam/MIMIC-CXR-annotations data/mimic
   rm -rf data/mimic/.git
   ```

2. Download corresponding images from [PhysioNet](https://physionet.org/content/mimic-cxr-jpg/2.0.0/)

   ```bash
   python tools/download_mimic_heldout.py --out_dir "$DATA_ROOT/mimic-cxr-jpg" --user <physionet_user>
   ```

## 3) Prepare anatomical priors

ASH-MIL uses patient-specific cardiac and pulmonary masks generated by [CXAS](https://github.com/ConstantinSeibold/ChestXRayAnatomySegmentation) as soft anatomical priors to guide query attention in the corresponding branches. Precompute these masks once for all training and evaluation images.

For each image, save both masks in a single `.npz` file under the keys `cardiac` and `pulmonary`.

### CXR8 priors

```bash
python cxas/precompute_ashmil_priors.py \
  --input_dir "$DATA_ROOT/CXR8/images" \
  --output_dir "$DATA_ROOT/CXR8/cxas_mask" \
  --gpus 0 \
  --batch_size 4
```

### MIMIC priors

```bash
python cxas/precompute_mimic_priors.py \
  --ann "data/mimic/annotations/221v2hiqualnihsplit.json" \
  --mimic_files_root "$DATA_ROOT/mimic-cxr-jpg/files" \
  --mimic_metadata_csv "$DATA_ROOT/mimic-cxr-jpg/mimic-cxr-2.0.0-metadata.csv" \
  --output_dir "$DATA_ROOT/mimic-cxr-jpg/cxas_mask" \
  --gpus 0 \
  --batch_size 4
```

## 4) Train

```bash
bash scripts/train.sh
```

### train/val/test split

- `--split_mode csv`: uses the patient-level 8:1:1 split in `data/cxr8/cxr8_split/`.
- `--split_mode auto`: builds a new patient-level 8:1:1 split from `Data_Entry_2017.csv` with `--split_seed`.

## 5) Evaluation (NIH + MIMIC)

```bash
bash scripts/eval.sh
```
